## 60-second explanation
I built CloudGuard to understand cloud security as connected configuration decisions rather than
a list of buzzwords. It normalizes JSON or YAML into typed resources and evaluates 41 modular rules.
I modeled four environments: a secure baseline, a startup, a deliberately vulnerable legacy mock
and an enterprise review. The startup has ten resources and twenty findings. Scoring considers
privilege, public permissions, data classification and protection gaps; the dashboard shows every
contribution and prioritizes remediation. Secret-looking values are redacted and report HTML is
escaped. Tests validate safe and unsafe cases. It is a synthetic batch lab, with a separately gated
read-only AWS inventory export and clearly documented policy-evaluation and reachability limits.
